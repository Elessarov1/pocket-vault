# Contributing

Bug reports and security reports are welcome through the repository issue
tracker. Do not include real passwords, bot tokens, or other
sensitive data in reports.

Pocket Vault uses a source-available public license and may also be offered
under separate commercial terms. For that reason, external code contributions
are not accepted unless the contributor first enters into a separate written
contributor license agreement with the project owner that permits relicensing,
including commercial licensing.

Opening an issue does not transfer copyright. Do not submit a pull request until
the contributor license agreement process has been completed in writing.
